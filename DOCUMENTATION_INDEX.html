🏗️ Project Overview

Digital Mail Letter is a full-stack web application that allows users to send physical letters through a digital interface. Users fill out a form, pay via Stripe, and the system automatically prints and mails their letters using the Lob API.

Key Features:

  • 📝 Professional letter templates
  • 💳 Stripe payment integration
  • 📧 Email confirmations and tracking
  • 🖨️ Automatic printing and mailing via Lob API
  • 📊 Admin dashboard for monitoring
  • 🔄 Real-time job processing

🌐 Frontend (React)

Main Application (web/src/App.tsx)

Purpose: Main user interface for creating and sending letters

Key Features:

  • Template selection with live preview
  • Sender and recipient address forms with validation
  • Message composition
  • Stripe payment integration
  • Form validation and error handling

Success Page (web/src/SuccessPage.tsx)

Purpose: Displays confirmation after successful payment

  • Real-time job status polling
  • Dynamic status display (processing, completed, failed)
  • Tracking information display
  • Email confirmation details

⚙️ Backend (Node.js/Express)

Main Server (server/src/index.ts)

Purpose: Central API server handling all requests

Key Sections:

  • Server Setup: Express configuration, CORS, middleware
  • Stripe Integration: Checkout sessions and webhooks
  • API Routes: Health checks, job management, templates
  • Email System: Nodemailer configuration and sending

Background Worker (server/src/worker.ts)

Purpose: Processes letter jobs in the background

  • Reads jobs from file/database
  • Generates PDF from template
  • Sends to Lob API
  • Updates job status
  • Sends confirmation email

🗄️ Database & Storage

Prisma Schema (server/prisma/schema.prisma)

Purpose: Database schema definition

model Job { id String @id @default(cuid()) templateId String? body String? sender Json recipient Json service String? options Json? status String tracking Json? stripeSessionId String? customerEmail String? createdAt DateTime @default(now()) updatedAt DateTime @updatedAt }

File Storage (server/src/store.ts)

Purpose: Fallback storage when database unavailable

  • readJobs() - Read jobs from JSON file
  • writeJobs() - Write jobs to JSON file
  • readConfig() - Read configuration
  • writeConfig() - Write configuration

🔌 Integrations

Stripe Payment Integration

  • Checkout Session: /api/checkout
  • Webhook Handler: /api/stripe/webhook
  • Price: $2.50 per letter

Lob API Integration

  • File: server/src/providers/lob.ts
  • Purpose: Send physical letters
  • Features: PDF generation, address validation, tracking

Email System

  • Service: Gmail SMTP
  • Types: Receipt emails, tracking updates, error notifications
  • Configuration: Nodemailer with timeout handling

🐳 Deployment

Railway Deployment

  • Platform: Railway.app
  • Container: Docker
  • Database: PostgreSQL
  • Domain: digitalmailletter.com

Environment Variables

STRIPE_SECRET_KEY=sk_live_... STRIPE_WEBHOOK_SECRET=whsec_... LOB_API_KEY=live_... EMAIL_USER=your@gmail.com EMAIL_PASS=your_app_password ADMIN_PASSWORD=your_admin_password DATABASE_URL=postgresql://...

🔍 API Endpoints

Public Endpoints

  • GET / - Main application
  • GET /api/health - Health check
  • POST /api/checkout - Create Stripe session
  • GET /api/jobs/by-session/:id - Get job by session ID
  • GET /api/templates/:id/preview - Template preview

Admin Endpoints

  • GET /admin - Admin dashboard
  • POST /api/admin/login - Admin authentication
  • GET /api/admin/jobs - List all jobs
  • GET /api/admin/health - System health stats
  • GET /api/admin/errors - Error monitoring

📊 Admin Dashboard

URL: https://digitalmailletter.com/admin

Password: Set via ADMIN_PASSWORD environment variable

Features:

  • System Health: Real-time statistics
  • Job Management: View, requeue, delete jobs
  • Error Monitoring: Failed job details
  • Authentication: Password-based login

🐛 Troubleshooting

Common Issues

  • Email Timeouts: Check Gmail app password, verify SMTP settings
  • Lob API Errors: Verify API key, check address format
  • Database Connection: Check DATABASE_URL, verify Prisma schema
  • Stripe Webhook Issues: Verify webhook secret, check endpoint URL

Debugging Tools

  • Railway Logs: Real-time application logs
  • Admin Dashboard: Job status and errors
  • Browser DevTools: Frontend debugging
  • Stripe Dashboard: Payment monitoring

🚀 Getting Started

Prerequisites

  • Node.js 20+
  • Docker (optional)
  • Railway account (for deployment)
  • Stripe account
  • Lob account
  • Gmail account (for emails)
