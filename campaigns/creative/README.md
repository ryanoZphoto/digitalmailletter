# Postcard Creative

- `postcard_front.svg` — editable vector source for a 6" x 4" postcard with bleed.

## Print specs
- Size: 6" x 4" (add 0.125" bleed all sides → 6.25" x 4.25")
- Provided SVG canvas: 1875 x 1275 px @ 300 DPI
- Safe area: inset 37.5 px from trim
- Colors: sRGB; avoid pure hairline strokes

## Export to PDF
1. Open in Figma, Illustrator, or Inkscape.
2. Ensure fonts are outlined or embedded.
3. Export as PDF/X-1a or high-quality print.
4. Keep bleed included; no crop marks unless your vendor requests them.

## Export to PNG/JPG (if needed)
- 300 DPI at full canvas (1875 x 1275)
- PNG preferred for sharp text/graphics

## Personalization (optional)
- Replace texts (title, subtitle, features, CTA, contact)
- Swap brand colors in gradients `#1d4ed8 → primary`, `#4338ca → secondary`
- Adjust badge price
